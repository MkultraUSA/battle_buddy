# Battle Buddy ATAK Icon Pack

This folder contains a small ATAK-friendly responder icon set.

Generated icons are in `dist/battle-buddy-response-icons/` and the importable
ATAK zip is `dist/battle-buddy-response-icons.zip`.

The source glyphs are Tabler Icons, licensed under MIT. The downloaded license
text is saved at `sources/tabler/TABLER_LICENSE`.

ATAK import path:

1. Copy `battle-buddy-response-icons.zip` to the Android device.
2. In ATAK, open the point/dropper tool.
3. Tap the settings gear.
4. Choose add icon set.
5. Select the zip.

The PNG files are intentionally 32x32 because ATAK displays that size cleanly
and larger icon assets do not provide much benefit on the map.
